# Railway deploy

Required variables:
- TELEGRAM_BOT_TOKEN
- GEMINI_API_KEY
- OPENAI_API_KEY
- MANUS_API_KEY
- ADMIN_USERNAME
- ADMIN_PASSWORD

After deployment:
1. Open Service -> Settings -> Networking.
2. Click Generate Domain.
3. Open `https://YOUR-DOMAIN/admin`.
4. Login with ADMIN_USERNAME / ADMIN_PASSWORD.
5. Telegram `/start`.
6. Upload a ZIP.
7. Send `সব error fix করে zip দাও`.

Do not paste API keys into GitHub or Telegram.
